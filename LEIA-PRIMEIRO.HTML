Bem-vindo ao NexZapp

Seu sistema profissional de disparos foi instalado corretamente.

Agora vamos fazer a inicialização do sistema passo a passo.

Inicialização rápida

Você aprenderá iniciar o sistema corretamente em poucos minutos.

Painel localhost

O NexZapp funciona diretamente pelo navegador usando localhost.

Sistema premium

Painel profissional preparado para uso completo e estável.

1

Abrindo o terminal

Você já abriu a pasta do NexZapp para acessar este tutorial.

Agora olhe na PARTE SUPERIOR da janela da pasta.

Existe uma barra mostrando o caminho da pasta.

EXEMPLO:
C:\Users\Desktop\NexZapp

Clique exatamente em cima desse caminho.

Depois apague tudo e digite:

DIGITE:
cmd

Agora aperte ENTER.

O terminal preto irá abrir automaticamente dentro da pasta correta do sistema.

2

Ligando o sistema

Com o terminal aberto, copie o comando abaixo.

COMANDO:
node index.js

Cole dentro do terminal e aperte ENTER.

O sistema começará iniciar automaticamente.

Não feche o terminal enquanto estiver usando o painel.

3

Abrindo o painel

Depois que o sistema iniciar, abra seu navegador.

Agora acesse:

LOCALHOST:
http://localhost:3000

Cole no navegador e aperte ENTER.

O painel NexZapp abrirá automaticamente.

4

Conectando o WhatsApp

Após abrir o painel, entre na tela de conexão e escaneie o QR Code.

Abra o WhatsApp no celular
Clique em aparelhos conectados
Escaneie o QR Code do painel

Sistema iniciado

O NexZapp foi iniciado corretamente.

Agora basta utilizar o painel normalmente.
